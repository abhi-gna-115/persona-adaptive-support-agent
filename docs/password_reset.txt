Title: Password Reset Guide

Users can reset their password from the login page by selecting "Forgot Password".
A password reset email will be sent to the registered email address within 2 minutes.
The reset link is valid for 15 minutes.

If the reset email is not received, users should check spam or junk folders.
Users should also confirm that they are using the email address registered with their account.

If multiple reset attempts fail, the account may be temporarily locked for security reasons.
In that case, the user should wait 30 minutes before trying again.

Support should escalate the issue if:
- The user cannot access the registered email.
- The user suspects unauthorized access.
- The reset link is expired repeatedly.
